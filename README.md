# Moksha Fabrics

Website and SEO foundation for Moksha Fabrics, a textile business based in Surat, Gujarat.

## Stack

- Next.js
- React
- TypeScript
- App Router

## Catalogue architecture

Fabric catalogue data lives in `lib/fabrics.ts`. Product/category entries are intentionally kept as placeholders until verified Moksha Fabrics specifications, images and commercial details are supplied.

## Before production

- Confirm the production domain and replace placeholder canonical URLs if required.
- Replace the placeholder enquiry email with a verified business contact.
- Add verified business address/phone details where appropriate.
- Add real fabric images and product specifications.
- Connect the enquiry flow to the preferred business contact/CRM.
- Run a production build and deployment check.
